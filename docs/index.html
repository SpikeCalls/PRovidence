<crawl_layer>

    
Eight legs. Six rules. One eye.

    

      
01 · crawl_layer
Maps before it touches
Walks every repo, every file, every language. Writes nothing. Builds a map first.

      
02 · fix_protocol
Reproduce first
A fix is only applied if the check fails right now. Then it re-runs the check. Still failing? It rolls back.

      
03 · finding_schema
Every bug is a typed record
{ "kind": "leaked-secret",
  "severity": "critical",
  "confidence": 0.9,
  "blast_radius": ["src/env.ts"],
  "status": "reproduced" }

      
04 · second_brain
Four legs code. Four farm.
Every finding becomes a note. Every note links to its file and module. Opens as a graph in Obsidian.

      
05 · safety_web
Hard limits in code
Never pushes to main. Never touches secrets. Never deletes. Never rewrites history. Not a prompt — a throw.

      
06 · morning_report
One-minute summary
Fixed, left with evidence, and the line that matters most: "What did I not see?"
